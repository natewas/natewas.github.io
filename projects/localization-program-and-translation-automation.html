Challenge

A global enterprise client's academy offers 750+ English-language eLearning courses but lacked a scalable localization process. The manual workflow took 38–60 minutes per course and left key components untranslated:

  • Video captions remained in English.
  • Internal navigation and links redirected to untranslated content.
  • Non-English terms were poorly searchable.

These gaps created barriers for non-native speakers and posed compliance risks in regulated global markets.

Solution

A custom utility extracts course text and .vtt captions from SCORM, converts them to structured JSON, batch-translates into 15 languages via SmartCat's CLI, and reintegrates every asset while preserving structure and LMS compatibility.

Localizes catalog pages, metadata, learning paths, UI navigation, and multimedia captions, not only the core course content.

Regional SMEs review each output for context and accuracy, and version control is built into the utility for fast iteration.

My Role

  • Owned the end-to-end design, development, and deployment of the program.
  • Designed the automation workflow and system architecture.
  • Developed the custom SCORM-to-JSON utility in Python.
  • Integrated the SmartCat CLI with the client's LMS and authoring pipeline.
  • Collaborated with global stakeholders to validate and test localized outputs.
