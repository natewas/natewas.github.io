Challenge

Launching a global certification program for a large QMS and manufacturing SaaS company, serving admins, partners, employees, and developers, meant scaling a fair, secure, and rigorous exam process. The client needed to evaluate hundreds of learners with varied workflows, prevent question fatigue, and eliminate manual work like account creation and badge delivery.

Solution

Authored 800+ questions targeting core competencies across every user type, refined each with stakeholder SMEs to balance clarity and challenge, and tuned the exam with pilot data before launch.

Python and JavaScript workflows ran enrollment, grading, and sandbox setup; the Credly API auto-issued each digital badge the moment an examinee passed; and a dynamic email system delivered credentials, scores, and next steps, with no admin involvement.

A Domo dashboard unified Qualtrics, Skilljar, and Credly data into one live view, surfacing real-time program health and learner feedback to leadership after every exam.
